Overview

Ingest Tanium linux_servers_full_agent_status.csv (~807 hosts), SSH with up to 10 cred profiles, assess Tanium/Falcon/Arc/rsyslog, remediate via Ansible when DRY_RUN=false, output EXEC-*.xlsx.

Active delivery: TANIUM_REPORT_MODE=drop — upload to reports/drop/.

On hold: O365 email fetch, Atlas API scrape.

End-to-end flow

  1. A Report — SCP to reports/drop/
  2. B Trigger — initiate_run.py or monthly_controller.py
  3. C Snapshot — atlas_fetch.py → archive + incoming
  4. D Ingest — csv_source.py → DB + EXEC inventory
  5. E Fleet — pipeline.py parallel SSH, compliance, Ansible
  6. F Excel — reporting/excel.py → reports/generated/
[drop] → [snapshot] → [parse] → [parallel SSH ×807] → [EXEC-*.xlsx]

Architecture

Tanium → drop → pipeline → ssh_collector + compliance → ansible_exec → Excel
         secrets/credentials.json          ssh_compat.py              playbooks/

SSH mechanism

  • ssh_compat.py — legacy KEX, ssh-rsa, known_hosts accept-new
  • Paramiko 3.x + OpenSSH/sshpass fallback
  • Auto ssh-keygen -R on host key mismatch
  • Try cred-01…10; remediation uses winning cred only
